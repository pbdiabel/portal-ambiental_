# EcoVida - Portal Web Temático

Proyecto académico para Herramientas de Programación III.

## Archivos
- 5 páginas HTML interconectadas
- CSS propio con variables y responsive
- Bootstrap 5
- JavaScript para validación del formulario
- 8 imágenes locales en SVG
- Video incrustado
- Tabla con thead/tbody/tfoot
- Formulario de contacto

## Para ejecutar
Abrir `index.html` en un navegador. Para una experiencia completa también se puede abrir la carpeta en VS Code y usar Live Server.

## Publicación
El proyecto puede subirse a GitHub y publicarse con GitHub Pages o a Netlify.
